SUPABASE (Cloud)
├─ PostgreSQL database
├─ 6 tables: settings, trades, ticks, ml_models, signal_performance, decision_logs
├─ Automatic REST API (no need for Parse Server)
├─ FREE tier: 500MB, 50K users, unlimited API calls
└─ Real-time optional (WebSockets)

INDEXEDDB (Browser Cache)
├─ Offline-first storage
├─ Auto-sync every 5 minutes
├─ Zero server cost
├─ Works without internet
└─ Seamless fallback

FRONTEND API FLOW
┌────────┐
│Browser │
└───┬────┘
    │ 1. Call API.method()
    ▼
┌──────────────┐
│SupabaseDB    │  ◄─── REST API Call
│              │
│1. Try Supabase REST
│2. Save to IndexedDB
│3. Fall back if offline
└──────┬───────┘
       │
       ├─→ Supabase ─→ PostgreSQL
       │
       └─→ IndexedDB ─→ Browser Storage

SETUP (5 MINUTES)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 1: Create Supabase Project
  - Go to https://supabase.com
  - Create new project (takes 2 min)
  - Get URL + anon key from Settings

Step 2: Create Database Tables
  - Go to SQL Editor
  - Copy SQL from SUPABASE_SETUP.md
  - Run it (creates 6 tables with indexes)

Step 3: Set Environment Variables
  - Copy VITE_SUPABASE_URL
  - Copy VITE_SUPABASE_ANON_KEY
  - Copy SUPABASE_SERVICE_ROLE_KEY
  - Add to .env file

Step 4: Test Locally
  - npm install (installs Supabase)
  - npm start (run server on :3000)
  - Open browser, check data syncs

Step 5: Deploy to Render
  - git add . && git commit -m "Supabase migration"
  - git push origin main
  - Go to Render, add env vars, deploy
  - Done!

TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "Supabase URL not set"
  → Set VITE_SUPABASE_URL in .env

❌ "API returned 401/403"
  → Check VITE_SUPABASE_ANON_KEY is correct
  → Verify RLS policies allow access

❌ "No data in tables"
  → Check tables exist in Supabase dashboard
  → Check RLS policies (should allow SELECT/INSERT/UPDATE)
  → Try INSERT manually in Supabase SQL editor

❌ "IndexedDB empty"
  → App hasn't synced yet (happens on next action)
  → Force sync: Open DevTools → Application → Clear IndexedDB → Refresh

❌ "ML endpoints return errors"
  → Check server.js /api/ml/* endpoints exist
  → Check HUGGINGFACE_API_KEY is set
  → Check server logs for errors
